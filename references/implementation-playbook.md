# Implementation Playbook

## Phase: Discover

- inventory journeys and campaigns
- define preliminary states and thresholds
- identify value moments
- map channels and surfaces
- map data and capabilities
- document governance and measurement

## Phase: Diagnose

- identify gaps and overlaps
- quantify state populations when data permits
- identify candidate transitions
- classify surfaces
- identify data-quality risk
- select pilots
- define dependencies

## Phase: Design

- build state definitions
- build journey decision trees
- create message briefs
- define contact governance
- define measurement and controls
- confirm privacy, accessibility, legal, and operational gates

## Phase: Pilot

- launch with limited scope
- use a control or holdout where feasible
- monitor negative outcomes
- validate ownership
- revise or stop weak treatments
- preserve no action

## Phase: Scale

- automate validated logic
- expand channels
- centralize prioritization
- improve self-service
- add confidence-aware decisioning
- monitor drift
- schedule review and retirement

## Capability gate

For every journey, ask:

- Can the signal be detected?
- Can the customer be identified?
- Can eligibility be evaluated?
- Can completed actions be suppressed?
- Can competing treatments be resolved?
- Can the experience be constructed?
- Can the channel execute at the needed time?
- Can the response update state?
- Can incremental impact be measured?
- Can privacy, accessibility, quality, and approval requirements be enforced?

## Roadmap priority

Sequence work by:

- customer value
- business value
- confidence
- feasibility
- time to learn
- dependency reduction
- reusable infrastructure
- operational risk
