# Journey Design

## Standard formula

**current state → signal → eligibility → need → treatment → behavior check → next state or exit**

## Journey brief fields

- customer objective
- business objective
- current state
- desired next state
- entry signal
- eligibility
- exclusions
- suppressions
- customer barrier or need
- evidence
- intervention type
- channel and surface
- timing
- cadence
- primary action
- wait window
- success condition
- non-response path
- escalation limit
- exit
- re-entry
- owner
- dependencies
- measurement
- control or holdout
- review or expiration date

## Intervention selection

Use the customer’s motivation and effort:

- motivated, difficult action: simplify, guide, or support
- motivated, easy action: nudge or remind
- weak motivation, easy action: explain value, persuade, or add proof
- weak motivation, difficult action: redesign the experience or do not send

Other valid interventions:

- recognize progress
- protect against service, payment, or account risk
- resolve friction
- suppress irrelevant contact
- take no action

## Reusable patterns

### Activation

Signal → assistance → behavior check → additional help → first value → exit

### Adoption

Active customer → missing strategic behavior → contextual education → usage check → reinforce or suppress

### Engagement

Healthy customer → achievable adjacent behavior → relevant value → behavior check → new engagement state or exit

### At risk

Decline signal → risk and value branch → low-cost intervention → response check → bounded escalation → recovery or suppression

### Win back

Lapse confirmed → reason-to-return branch → relevant proposition → response window → bounded escalation → restore or sunset

### Expansion

Demonstrated need or limit → eligibility → adjacent value → accept or reject → expand, continue, or suppress

## Journey review questions

- Is the customer need real and observable?
- Is the desired transition achievable?
- Can the signal be detected reliably?
- Can completed behavior be suppressed?
- Does another journey own this customer?
- Is the chosen channel justified by urgency and actionability?
- Does the escalation path end?
- Is no action possible?
- Can the outcome update state?
- Can incremental impact be measured?
