# Fictional Repeat-Purchase Example

## Context

A fictional specialty retailer wants to improve the transition from first purchase to a healthy repeat relationship.

## State model

- first purchase, product received
- first purchase, product not yet received
- likely replenishment need
- active repeat customer
- declining repeat customer
- dormant customer

## Journey principle

Do not send a generic repeat-purchase series. Use fulfillment, product type, expected use cycle, engagement, and service status to determine the next helpful action.

## Candidate treatments

- setup or care guidance
- accessory education when contextually relevant
- replenishment reminder when evidence supports timing
- service recovery when a problem is detected
- recognition for a repeat milestone
- no action when the purchase is non-repeatable or contact would not add value
