# Contributing

Thank you for helping improve the Customer Journey Lifecycle skill.

## Contribution types

Useful contributions include:

- clearer workflows and templates
- lifecycle patterns for additional business models
- stronger privacy, accessibility, or measurement guardrails
- evaluation prompts and rubrics
- portability or installation improvements
- fixes to ambiguous or overlapping instructions

## Requirements

1. Keep all content vendor-neutral and organization-neutral.
2. Do not contribute restricted, proprietary, or employer-owned source material.
3. Do not add exact performance claims or benchmarks without a public, citable source and clear context.
4. Use fictional examples.
5. Run all repository checks.
6. Add eval coverage for behavioral changes.
7. Explain the customer benefit and failure mode addressed by the change.

## Pull request checklist

- [ ] No restricted or identifying material
- [ ] No unsupported numerical claims
- [ ] `SKILL.md` remains concise
- [ ] Detailed content uses progressive disclosure
- [ ] Templates remain generally applicable
- [ ] Evals added or updated
- [ ] Validation scripts pass
